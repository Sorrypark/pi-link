# 파이 연결

노트북 브라우저에서 라즈베리파이에 접속하는 프로그램입니다. 터미널은 글자로, 파일 복사는 두 목록으로 합니다.

## 설치

1. [최신 버전](https://github.com/Sorrypark/pi-link/releases/latest)에서 `pi-link-버전.zip`을 받습니다.
2. 압축을 풉니다.
3. [Node.js](https://nodejs.org) 18 이상이 없으면 설치합니다.
4. `파이연결.bat`을 두 번 누릅니다.

접속 칸은 아이피 주소, 사용자, 암호입니다. `pi@192.168.0.10`처럼 적어도 됩니다. 포트를 적지 않으면 22로 연결합니다.

암호를 저장하면 이 Windows 사용자만 풀 수 있습니다.

## 업데이트

새 버전이 있으면 프로그램 안에 노란 업데이트 표시가 나옵니다. 업데이트를 누르면 받은 뒤 다시 켜집니다. 저장한 기기와 암호는 그대로 둡니다.

이 개발 폴더에서 `배포.bat`을 실행하면 지금 버전이 GitHub에 공개되고, 설치한 컴퓨터에 그 표시가 나타납니다.
